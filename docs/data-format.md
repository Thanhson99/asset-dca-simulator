# Data Format

## Folder Layout

```text
data/
  assets/
    stocks-kbs.json
  stocks/
    index.json
    download-queue.json
    FPT/
      2026.json
  gold/
    SJC_1L_HCM/
      2026.json
  corporate-actions/
    FPT.json
  exports/
```

Use one JSON file per asset per year. Daily data does not need one Excel sheet per year because JSON is easier to validate, version, merge, and load from GitHub Pages.

These files are generated by collector tools after real data is fetched and validated. The folder init scripts do not create placeholder JSON files.

## Frontend Stock Index

`data/stocks/index.json` is the small manifest used by the browser UI. It includes only symbols that already have local yearly JSON files, so the symbol input does not suggest unavailable data.

```json
{
  "assets": [
    {
      "symbol": "FPT",
      "name": "CTCP FPT",
      "exchange": "HOSE",
      "years": [2016, 2017, 2018, 2019, 2020, 2021, 2022, 2023, 2024, 2025, 2026]
    }
  ]
}
```

The collector rebuilds this file after stock updates and queue runs.

## Stock Download Queue

`data/stocks/download-queue.json` tracks the resumable 500-symbol backfill queue.

Each item has:

- `symbol`, `exchange`, `name`
- `status`: `pending`, `running`, `done`, or `failed`
- `attempts`
- `lastStartedAt`, `lastFinishedAt`
- `lastResult`, `lastError`

```json
  "assetId": "FPT",
  "assetType": "stock",
  "market": "HOSE",
```


## DCA Simulation Rules

For each strategy leg:

- `assetId`: asset to buy, for example `FPT` or `SJC_1L_HCM`
- `amount`: investment amount per period, for example `1000000`
- `frequency`: initially `monthly`
- `startDate`: first investment date
- `endDate`: optional; default is latest available date
- `priceField`: stock usually uses `close`; gold can use `sell` for buying and `buy` for exit value

If the selected buy date is not a trading day, use the next available market date. This must be explicit so charts are reproducible.

## Animation

Animation should not change the data. It only reveals existing simulation points over time.

Example: if the user chooses `10s`, split all simulation points over 10 seconds and reveal them in order from oldest to newest.
